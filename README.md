# Duy Nguyen — AI & Machine Learning Professional Portfolio

A static website prepared for GitHub Pages with **Home**, **About**, and **Artifact 1: AI & ML Timelines** sections.

## Deploy to GitHub Pages

1. Sign in to [GitHub](https://github.com) and create a **public** repository, for example `aiml-professional-portfolio`. Do not initialize it with a README if you plan to upload this folder as-is.
2. In the repository, select **Add file > Upload files** and upload the contents of this folder (not the outer ZIP). Upload `index.html`, `duy-nguyen-headshot.jpg`, `.nojekyll`, and `README.md` to the root of the `main` branch. If the upload dialog hides dotfiles, `.nojekyll` is optional for this site.
3. Commit the changes.
4. Go to **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then **Save**.
5. Once GitHub reports that Pages is deployed, open `https://YOUR-USERNAME.github.io/aiml-professional-portfolio/`.

## Notes

- The pages are sections of a single responsive `index.html` file; navigation uses `#home`, `#about`, and `#artifact` anchors.
- Keep `duy-nguyen-headshot.jpg` in the same directory as `index.html` so the photograph displays.
- This is an academic portfolio, so review its personal/professional details before making it public.
- The original AI & ML Timelines class presentation is *not* included. The current artifact page documents the timeline in website format and notes where original coursework can be linked when available.
